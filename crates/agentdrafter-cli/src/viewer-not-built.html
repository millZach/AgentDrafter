The viewer was not built into this agentdrafter

This binary was built without the viewer's page. Every command still works through the HTTP API at /commands.

To build the viewer in, install Node 24 or later, the Rust target wasm32-unknown-unknown and wasm-bindgen-cli, then run npm ci and npm run build in the repository's viewer/ folder, and build agentdrafter again. docs/viewer.md says more.
